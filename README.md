# 饭团 · 本地餐厅推荐 App

一个移动优先的餐厅决策原型。它会从个人餐厅库中一次推荐 1 家主选和 2 家备选，并根据待前往清单、距离、评分、预算与近期选择记录动态调整结果。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 已实现

- 添加、搜索和按菜系浏览个人餐厅库
- 按距离、评分区间、人均消费区间、菜系筛选
- 收藏时从高德地图搜索 POI，自动带入地址、距离、分类、评分、人均和特色标签
- 待前往餐厅优先推荐，选中后自动完成
- 一家主推荐与两家备选，可重新随机
- 近期选择餐厅自动降低推荐权重
- 根据用餐偏好展示周边新店，并可加入餐厅库
- 选择后展示路线信息并跳转高德地图导航
- 所有餐厅数据与选择历史保存在浏览器 `localStorage`

当前版本使用演示餐厅数据和本地推荐算法，不依赖后端服务。

## 接入高德地图

1. 在高德开放平台创建应用并申请「Web服务 API」Key。
2. 复制 `.env.example` 为 `.env.local`。
3. 将 Key 填入 `VITE_AMAP_WEB_SERVICE_KEY` 后重启开发服务。

```env
VITE_AMAP_WEB_SERVICE_KEY=你的高德Web服务Key
```

未配置 Key 时，收藏页面会明确显示 `DEMO` 并提供示例搜索结果。高德对部分餐厅可能不返回评分或人均消费，确认收藏页面会保留可编辑输入框供用户补充。

当前前端直连方式适合本地原型。正式上线时应使用服务端代理高德请求，并在服务端保管 Key、配置调用额度与错误监控。
